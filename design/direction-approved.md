# 当前视觉方向已确认

本轮是同一项目已选定方向后的迭代，符合 huashu-design 的三方向门豁免「同一项目内已选定方向后的迭代」。该 skill 的生产级后端系统完整原型流程不适用于本 App；采用其已有 context 与可读性复核，工程和状态系统以 Taste app-screen 指导为主。无需重新要求用户选三版。

用户原话：
- 「可以差不多是这种，节省时间，大一点的图你就用四宫格生成然后裁剪。小图标的12宫格也无所谓，反正清晰效果达标，同时节省用户加载速度即可。就是image要optimized，但是不要变模糊。」
- 「方向对了，但线条和颜色需要再柔和一些」
- 「你需要预留好空间呼吸来方便crop啊」
- 库存红色「不是大红或亮红，是舒服且匹配整体的」；并要求同步状态使用有意义的颜色。

保留菜篮子名称、品牌 mark、字体、页面布局，使用叶绿/暗砖红/赭色/中性色传达已有、耗尽、等待/离线、未连接。颜色同时配文字与控件状态。原生 checkbox 保留键盘与屏幕阅读器行为，采用浅底空心绿框与绿勾。食品采用日系 2D 动画绘制，独立裁剪，菜品至少 15%透明边距，小图 192px，详情菜品 960×640。
