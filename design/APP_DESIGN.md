# Little Basket App 设计说明

## 用户与任务

用户主要在手机上，出门前选购日常食材，或从熟悉的菜决定买什么；在超市勾掉已买的东西；回家后手动记录调料余量。新菜通常通过对话整理，而不是在手机里填写长表单。

三个独立对象贯穿设计：本次待买清单、持续库存、带日期的购买记录。用户日常重置的是清单，不能误删另外两项。

## 视觉与结构

- 名称：菜篮子 · Little Basket。
- 地面：低彩度石绿白 `#f3f5f0`；卡片用米白；文字用深叶绿 `#293728`，操作色 `#506638`。
- 标题与正文采用设备已有的中文字体；衬线只承担菜谱页的简短提问，不依赖字体下载。
- 食材用一致的内嵌 SVG，菜谱用对应菜肴的盘、汤锅与原料插画。图片表示食材身份，不是销售装饰。
- 四个手机目的地：选购、清单、菜谱、小厨房。持续可达的底部导航；库存、记录不挤入购物清单。
- 选购、清单、小厨房使用直接的 App 页头，不放网页式开场大图；小厨房先显示调料滑块，生鲜与历史在相邻页签。
- 320 px 收为两列选购／单列菜谱；390 px 三列食材、两列菜谱；桌面扩展出本趟菜单侧栏。所有页面禁止横向整页滚动，分类条可独立滚动。
- 44 px 触控目标、表单 16 px、文字辅助信息至少 12 px；原生 dialog 管理焦点，底部 sheet 适配手机与安全区域。

## 应用的能力与取舍

已阅读并采用项目安装的 `design-taste-frontend` App-screen 路由和 `frontend-design`。抽取结果为 `editorial-greeting`，seed `1648972566`；方向记录在 `.taste-skill/direction.json`。其个人工作区的基调用于菜谱；用户明确要求手机 App 后，选购／清单／库存改用紧凑工作界面。没有使用营销页 AIDA、GSAP 滚屏、展示 KPI、伪数据或 3D。

`--keep palette,type` 保留本厨房的石白、叶绿与系统中文字体。原方向中桌面 L 形侧栏不适合只有四个去向、主要靠拇指操作的手机 App，改成手机底部导航和桌面顶部导航。网格中食材和菜谱都是同类对象，使用重复卡片有实际扫描目的。

14 个上游 skill 是能力库。工业、极简、柔和、生图、Stitch、花叔等路由各有流程，不作为相互叠加的强制样式。没有调用未加载的原生设计角色；设计角色的来源和原生转换状态单独记录在安装报告。

## 交互约定

- 点食材加入当次清单；同名只记一行，别名统一到同一原料 ID。
- 选菜合并原料用量。调味料用「适量」，已有调料按库存略过；份量是参考，不代表库存实际克数。
- 勾选表示确实买到，才写入历史；取消勾选撤回关联记录。清空旧清单不回滚真实已买历史。
- 余量由用户滑动；做菜与调整份数不推算消耗。买新的一份重设满格。后续手动余量调整优先于购买撤销时的旧快照。
- 七天内的重复购买／已有库存，在明确确认之前不加入；一张提醒 sheet 可逐项选择。库存未知时不显示假定数量。
- 每日自动重置默认关闭；开启后只在下次打开／返回／切页时跨日重置，时区为马来西亚。不会后台清理。
- 新菜可在 App 内添加编辑，也可由后续对话更新内置数据；稳定 ID 与迁移保留用户记录。做法细节、笔记、学习链接放在详情里。

## 验证证据

浏览器回归位于 `tests/test_app.py`；安装校验位于 `scripts/verify_design_capabilities.py`。截图与机器检查报告写入 `.test-results/`，包括当前手机选购、清单、调料、生鲜、历史、提醒和桌面布局。图中的采购操作是自动化测试场景，不是用户的真实购买数据。

检查覆盖：320、360、390、430、768、1024、1440 px；清单去重、做法修改、配方切换、余量滑块、历史日期窗口、每日开关、手动重置、导入导出、存储异常保护。独立截图肉眼查看后调整了小字号、低对比说明、窄屏插画溢出，以及库存页首屏看不到滑块的问题。

全页检查器针对桌面工作台提出的 “below-fold” 警告，对 27 种可滚动浏览的食材目录不构成必须全部放在首屏的要求；分类、搜索和第一批真实食材必须首屏可达。米白作为小面积表面与反白文字的配色警告按厨房材料色保留。12 px 只用于辅助说明，主要食材名称、做法与库存内容保持 14 px 以上。

## 范围

这是完整可操作的静态单文件 App，提供家庭专属链接与 Supabase 同步；没有注册登录流程、保质期预测、费用统计或多瓶库存台账。HTML 不依赖第三方资源，打开后交互可以断网使用；手机系统文件预览器未必执行脚本，使用浏览器或静态托管更合适。当前已在 Chromium 验证，未宣称在真实 iPhone／Safari 上测试过。


## 家庭同步与这轮交互修正

家庭专属链接直接连接，无注册、邮箱或密码页面。链接是家庭共享钥匙，不写入公共 HTML、构建配置或 JSON 备份。普通网址在未连接设备无法读家庭数据。冲突采用整份记录确认与替换前备份，避免静默丢失家人更改。

添加食材改为自定义图标选单，显示图标、名称、分区与库存提示，支持方向键、Enter、Escape。所有弹窗明确设置 inset:0 和 margin:auto，在手机与桌面居中，内容过长在弹窗内滚动。调料余量和生鲜库存各有添加入口；调料初次余量默认未记录，库存录入不会当成采购。

保持既有石色与叶绿视觉，不重新抽取方向。轻量动画只反馈操作，遵循 reduced motion。浏览器验证覆盖 320 / 390 / 768 / 1440 px；未声称实际 iPhone Safari 验收。

来源链接采用自动续行，不增加添加按钮。每条填入后补一个空输入，空行不保存，可清空删除，学习笔记中按来源列出。保留旧 source 字段与首个链接兼容，新增 sources 集合随备份和家庭同步保存。自定义食材下拉的轻阴影用于悬浮选单，属于主设计 skill 明确允许的浮层，不用于静态卡片。

勾选方格统一为空心叶绿边框与浅色底，选中后只显示叶绿对勾。保留原生 checkbox、关联 label、Space 操作和 focus 状态；采购勾选和菜谱选中标记也使用相同的空心视觉。高对比模式恢复系统控件。

## 全套食物插画与状态设计

用户确认 2D 动画方向后，按更柔和的线色与色块扩展为 54 张食物插画及 1 张菜篮主插画的独立透明 WebP，来源和裁切规则见 assets/illustrations/README.md。修复共用图集取景造成的相邻素材串入；完整轮廓居中放入留有呼吸空间的独立画布，菜图保持至少 15% 留白。手机卡片中可区分薯苗和豆苗、炒蛋和肉碎，原有操作图标保持简单清楚。整套优化后约 1.36 MB，无外部素材请求。

沿用 taste、frontend-design 与花叔的既有方向审查：不重排品牌和主页面，降低次要控件存在感，提高真实状态的可读性。「默认分类」移到分类栏下方、食材分组上方，13 px 无边框文字按钮；点击向右展开两列四项浮层，使用米白底、细绿边与浅绿选中态，选好收回；点外部、Tab 离开或 Escape 取消。箭头提示展开与收回，160–180 ms 淡入与水平位移遵循 reduced motion。保留 44 px 点击高度、menuitemradio 状态、键盘方向键与关闭后焦点返回；窄屏浮层不越出页面边缘。米白、叶绿之外，柔和砖红 #98534e 表示耗尽或错误，赭色 #826329 表示待同步，文字和图标同时说明状态。

常备余量包含米、油、燕麦、Milo、蛋白粉等慢消耗品；滑块步进 1%，按当前值连续插值砖红、柔赭、原叶绿。填充、滑钮、大号百分比和两端说明随拖动实时更新颜色；两端文字仅在各自半区逐渐加粗：低于 50% 时「用完了」向左加粗，高于 50% 时「刚买的」向右加粗，50% 时两端均为基础字重。采用连续曲线与 80 ms 线性缓动；未知库存保持中性。去掉重复的小百分比，减轻阅读负担。遵循 reduced motion。

生鲜改为三档原生 range（min=0、max=2、step=1），仅有「用完了／还有／很多」。非当前档位字重 400；当前档位分别为柔和砖红 #98534e、叶绿 #506638、深绿 #35634b 并加粗；三点标记清楚展示停靠位置，文字同样可点选，键盘方向键与 Home/End 可操作。未知库存保持灰色「待确认」，初始中点不代表已确认拥有；点击中点可明确确认。沿用已有库存布尔状态，旧的「还有」默认中档；手动档位作为 stockEdits 的可选 freshAmount 保留，未改动余量、购买历史和清单重置语义。选购中已有库存用更深的绿加粗，其余标签维持原样。历史支持新旧排序、单笔删除及撤销，购买关联和后续手动库存调整分别保护。

## 品牌、桌面安装与快速清单

按用户选定的方案一，页首芽苗改为一只藤编菜篮和叶菜的柔和 2D 插画。名称不变，中文字重 600，英文改为 Little Basket、10 px、收紧字距。品牌母图和处理步骤见 `assets/brand/README.md`；页首 WebP 约 8 KB，安装图标另保留不透明底和系统裁切安全区。菜谱页右侧菜篮放大约 12%，向内微调，手机不压住文字。

小厨房页签仅用 sessionStorage 保留刷新位置，离开后再进默认常备余量，不将家庭成员的导航互相同步。生鲜三档说明未选中为 400，只有选中档位为 750。购买历史删除撤回对应库存来源，覆盖清单已重置及重复购入后依次删除的场景；后续真实手动库存调整优先。

选购页右下悬浮篮子固定在底部导航上方并避开安全区域，保留 64 px 触控和末尾滚动留白。待买数量去重后计算，已买项目不占预览。底部预览 sheet 显示食材插画、名称、参考量和柔和砖红移除按钮；撤销在弹窗内可直接点。桌面使用居中紧凑弹窗。完整清单继续承担采购勾选、进度、缺料和分享，避免两个页面抢相同权重。菜谱食材移出写入当趟 `trip.omitted`，不会伪造家里有，也不改菜谱；随家庭同步和备份保存，开新一趟清空。重新选择菜谱或主动加回食材可恢复。

生产站点提供独立窗口 PWA，HTTPS 下注册同路径 service worker，只缓存公开页面和图标，不缓存家庭 API 或密钥。manifest 的入口和 scope 都是相对路径，兼容 Little-Basket 子路径；iOS 使用 Apple touch icon。安装和家庭连接分开：系统存储隔离时只需再粘贴一次私人链接，不出现账户密码界面。真实 Chromium 验证安装元数据与离线刷新；实际 iPhone／Safari 安装仍由家庭设备验收。

采购备注分为 `trip.itemNotes`（每个食材最多 500 字）和 `trip.note`（本次总备注最多 2000 字），只属于当前一趟。物品备注用编辑图标和折叠区显示，平时可直接读两行摘要；展开后 16 px 输入不触发手机放大。预览与完整清单共用同一份备注，输入即时保存，不重画输入框或移动光标。清单总备注置于进度区之后、食材之前，空时只占一行。云端拉取与跨日重置避开正在输入的备注，避免编辑中被替换。新字段可选，旧备份继续兼容；导入验证 ID、重复项与长度。

## 选购视图密度

沿用已确认的 editorial-greeting 方向及字体、配色，按 taste 的单组件迭代流程与 frontend-design 审查，不重新抽取整页设计。选购区回答「今天要补什么」；同一批食材可按浏览习惯切换单列、双列、三列，默认双列。排序左对齐，视图切换右对齐，三枚一列／四格／九格 SVG 按钮不添加外框；浅绿选中底与 `aria-pressed` 同时表达当前状态，点击区域均为 44 × 44 px。

单列为插画、名称和库存提示、加入按钮的横向列表；三列收紧卡片间距与内边距，保留完整名称、库存说明和 44 px 加入按钮。用户指定的列数在 320–1440 px 保持一致，不被屏宽断点悄悄覆盖。没有列表重排动效，切换后立即呈现。显示偏好写入本机 `little-basket:preferences:v1`，与现有排序偏好一起保留；不写进家庭采购数据，不影响其他设备的显示习惯。

浏览器回归检查默认双列、三种布局的真实行列位置、键盘操作、搜索和排序兼容、刷新记忆，以及清单和库存不受视图切换影响。手机截图保存于忽略的 `.test-results/market-view-*.png`，检查了 320 / 390 / 430 / 768 / 1440 px 的完整名称与页面溢出。


## 插画层级、库存搜索与焦点修正

双列食材图使用 64 px、三列 52 px、单列 44 px；双列名称为 15 px / 600，库存说明保持次级。缩短的 Milo、炼奶、酸梅酱使用稳定 ID 兼容旧名称，保留旧称作为别名。厨房两分区搜索词分别保存在当前窗口的 sessionStorage，名称与别名均可匹配；结果为空时提供明确说明与清空入口。输入节点不会因过滤重建，中文组合输入结束后再过滤。添加库存时若筛选会隐藏新物品，清空目标分区筛选并滚动到该物品；库存添加中的分类选择不再覆盖慢消耗选项。

主内容的程序化焦点继续用于切页定位，单独取消容器 outline；控件的键盘 focus-visible 保留，备注 summary 也使用主题焦点色。没有全局禁止 focus，也没有在操作后强制 blur。清单预览改为浅绿标题／数量区、白色食材区、赭色撤销与绿色主操作；备注展开后的输入跨满列表宽度，避免窄屏编辑困难。

家庭用户与 UI/UX 专家两轮检查的发现、修正和剩余建议见 [本轮走查记录](reviews/2026-10-20-mobile-ui.md)。验收阶段按用户要求只在本地保存；发布以后续明确授权为准。


## 家庭链接可发现性与悬浮篮收窄

根据两轮审阅的剩余问题继续做组件迭代，不改变已确认的字体、品牌或页面结构。已连接设备的页首始终保留「家庭厨房」语境，下一行显示实时同步状态；未连接时仍显示「家庭同步」。同步面板只给家庭链接区使用浅绿底，账户状态改为无底色的简洁行，减少相邻同色卡片。链接区明确提供「复制家庭链接」主按钮与「分享给家人」次按钮，自动同步状态和手动重试置于其下。

复制结果在原面板中通过 role=status 告知，避免浮层挡住全局 toast 后用户看不到反馈。剪贴板拒绝或不支持时才展开可选中的只读链接；系统分享取消会说明连接不受影响。链接失效或设备断开时立即清空手动复制框并禁用复制／分享；异步复制结束时再次检查家庭连接，避免旧连接结果重新显示。专属链接不进入库存、清单、备份或页面缓存。

手机向下累计滚动 24 px 后，悬浮篮从 64 px 收到 44 px，保留图标、数量和完整无障碍名称；向上累计滚动 24 px、回到顶部、滑到底部、切换页面或键盘聚焦时恢复。缩小时第一次点击就打开预览。停下来阅读时不自动放大，减少重复遮挡和无意义动效。桌面保留 68 px，reduced-motion 下取消尺寸过渡；页面滚动以 passive 监听与 requestAnimationFrame 合并更新，不写入家庭数据。目录底部留白继续保证最后一项可以完整滚到悬浮篮上方。
